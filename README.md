# CB WhatsApp Gateway

WhatsApp Messaging API Provider platform by CodeBasket IT Services & Co.
Spring Boot 3 / Java 21 / MySQL 8 backend · React 18 / Vite / Tailwind frontend · Meta WhatsApp Cloud API · Razorpay · deployed on Ubuntu with systemd + Nginx (no Docker).
